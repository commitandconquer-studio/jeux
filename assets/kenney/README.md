# Modèles de Kenney (licence CC0)

Modèles 3D libres de [Kenney](https://www.kenney.nl), publiés en **CC0 (domaine public)** : utilisables
librement, sans obligation de citer (nous les citons quand même, par politesse).

| Dossier | Pack | Contenu |
|---|---|---|
| `mini-characters/` | [Mini Characters](https://kenney.nl/assets/mini-characters) | 12 personnages animés (marche, course, saut, mort, attaque…), accessoires |
| `car-kit/` | [Car Kit](https://kenney.nl/assets/car-kit) | voitures, camions, taxi, police, tracteur |
| `mini-forest/` | [Mini Forest](https://kenney.nl/assets/mini-forest) | arbres, rochers, clôture, tente, pont, plantes |

Seuls les fichiers GLB, leurs textures (`Textures/colormap.png`) et la licence de chaque pack sont gardés ici (les formats FBX et OBJ des packs sont redondants).
Ils s'affichent dans la visionneuse : `python3 tools/visionneuse.py`.

Les autres kits de Kenney (bâtiments, pirates, espace, château…) sont rangés dans `reserve/kenney/` (hors du dépôt, pas copiés dans le jeu web) : on les remonte ici quand on refait un monde avec.
