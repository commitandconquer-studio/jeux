# Sons de Kenney (licence CC0)

Bruitages libres de [Kenney](https://www.kenney.nl), publiés en **CC0 (domaine public)**. Seuls les fichiers utilisés par Traversée sont gardés ici ; la licence de chaque pack est à côté (`License-*.txt`).

| Pack | Utilisé pour |
|---|---|
| [Impact Sounds](https://kenney.nl/assets/impact-sounds) | les pas (herbe, planches, moquette, pierre, métal selon le monde), les chocs |
| [Interface Sounds](https://kenney.nl/assets/interface-sounds) | les clics, le ramassage d'un cadeau |
| [Digital Audio](https://kenney.nl/assets/digital-audio) | le cadeau doré, la chute dans le vide |
| [Music Jingles](https://kenney.nl/assets/music-jingles) | les petits jingles : début de partie, déblocage, record, fin de partie |

Le choix de chaque son se trouve dans `games/traversee/src/audio.rs` (`KenneySons`). Les autres packs téléchargés (RPG Audio, Sci-Fi Sounds, UI Audio, Voiceover Pack, Casino Audio) ne sont pas encore utilisés.
